# MediCare frontend

The frontend is a React + TypeScript application built with Vite.

## Local development

- Install dependencies with `npm install`.
- Start the dev server with `npm run dev`.
- Run `npm run build` for a production build and `npm run lint` for linting.

The Vite development server proxies `/api` requests to the backend at `http://127.0.0.1:8000`. Start the backend as described in the repository root README.
